# Atrium issue #92: simple glass shape shader

The issue is [wynter-yaxley/atrium-desktop#92](https://github.com/wynter-yaxley/atrium-desktop/issues/92). `VALIDATION.md` records the exact-pixel and controlled GPU results. `PERFORMANCE-AB.md` retains the original broader analysis, including the already merged comparison-shader work from #87. Four raw A/B CSV files are in `performance/`.

The `pixel-compare/` folder holds the comparison program and 147 synthetic before/after PNG pairs. From this directory, install Python, NumPy and Pillow, then run:

```powershell
./Run-PixelComparison.ps1
```

The expected result is `147 images, 0 changed`. The images are generated by the external Atrium graphics harness described in [#95's archive](../95-2026-11-17/README.md); this archived comparison itself needs no Atrium build or live desktop capture. The input images contain only synthetic content.
